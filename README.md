# LexiLoop

LexiLoop is a minimal Chrome extension designed to help users build practical English vocabulary through three words every day.

## V0.1 Features

- Three vocabulary words per day
- Meaning
- Pronunciation
- Part of speech
- Synonym
- Antonym
- Four example sentences per word
- Mark words as learned
- Daily progress indicator
- Persistent local progress
- Daily Chrome notification
- Minimal aesthetic interface
- No backend
- No external API
- No build step
